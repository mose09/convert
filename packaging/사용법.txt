========================================================
 SQL 마이그레이션 / 스키마 / ERD / 용어 도구 — 사용법
========================================================

[실행]
 1) 이 폴더를 '문서' 또는 '바탕화면' 등 "쓰기 가능한" 위치에
    압축 해제하세요. (Program Files 처럼 권한이 막힌 곳은 피하세요.)
 2) run.bat 을 더블클릭합니다.
 3) 잠시 뒤 웹브라우저가 자동으로 열립니다.
    - 안 열리면 브라우저 주소창에 직접 입력:  http://localhost:8501
 4) 종료: 검은 명령창을 닫으면 됩니다.

[상세 가이드]
 - 화면별 자세한 사용법은 이 폴더의 guide.html 을 더블클릭해서 보세요.
   (그림 포함 · 브라우저로 열림 · 인터넷 불필요)

[화면]
 - 스키마 추출 / 코멘트 증강 : Oracle DB · LLM 필요 → '설정' 화면에서
   접속정보를 먼저 입력하세요.
 - ERD 추출 / ERD 보기       : 스키마 .md 로 관계도 생성/열람.
 - 표준사전 적재 / 용어 검색 : 단어·용어·도메인 Excel 을 적재 후 검색.
 - 매핑 만들기               : 9컬럼 엑셀 → 매핑 MD.
 - SQL 마이그레이션          : mapper XML / Oracle .sql + 기존 매핑 → 변환 XML/SQL/리포트.
 - 설정                      : LLM · Oracle 접속정보(.env) 편집.

[참고]
 - 인터넷 없이 이 PC 안에서만 동작합니다. (외부로 아무것도 전송 안 함)
 - Oracle 스키마 추출은 Oracle Instant Client 가 필요할 수 있습니다.
   (설정 화면의 'Instant Client 경로' 참고)
 - 파이썬 설치가 따로 필요 없습니다 (폴더 안 python\ 사용).
 - 처음 실행 시 방화벽이 "localhost 접근 허용?" 을 물으면 허용하세요.

[이번 버전: Oracle 생성문 .sql]
 - PROCEDURE / FUNCTION / PACKAGE / PACKAGE BODY의 정적 SQL과
   TABLE.COLUMN%TYPE / TABLE%ROWTYPE 참조를 기존 매핑으로 변환합니다.
 - 결과는 원래 파일명과 입력 하위 폴더 구조를 유지합니다. 원본은 보존합니다.
 - AUTO_WARN은 일부만 변환됐거나 원문을 유지한 항목입니다.
   화면의 '수동 검토 항목'과 Excel Conversions 시트의 Status / Notes를 확인하세요.
 - 동적 SQL 문자열은 그대로 유지합니다. 중첩 DECLARE / 중첩 함수는
   파일 전체를 유지하고 경고합니다. AUTO는 Oracle 컴파일 성공을 의미하지 않습니다.
 - 입력/출력 폴더는 서로 포함되지 않는 별도 폴더로 지정하세요.

[검증]
 - Windows 10 / 11 64비트용입니다. 32비트 Windows와 ARM 전용 배포판이 아닙니다.
 - 실행 전 check.bat을 더블클릭하면 자체 검증을 수행하고
   selfcheck-result.txt에 결과를 저장합니다. 인터넷, DB, LLM 없이 검사합니다.
 - 실제 Oracle 컴파일/실행과 DB/LLM 연동은 이 자체 검증에 포함되지 않습니다.
 - BUILD-REVIEW.txt: 제작 방식, 검증 완료 항목 및 미검증 항목.
 - SHA256SUMS.txt / build-info.json: 파일 무결성 및 포함 의존성 정보.
 - Python과 의존성은 함께 포함되어 있어 별도 pip 설치가 필요 없습니다.
 - 기존 버전 폴더에 덮어쓰지 말고 별도 폴더에 압축을 푼 후,
   사용하던 매핑 YAML과 필요한 설정(.env 등)만 옮기세요.

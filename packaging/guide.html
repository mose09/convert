아이콘 의미 — 오프라인 접속 불필요 · DB Oracle 접속 필요 · LLM LLM 접속 필요. DB/LLM 태그가 붙은 화면은 먼저 「설정」 화면에서 접속정보를 넣어야 동작합니다.

1시작하기

  1. 받은 압축파일을 쓰기 가능한 폴더(문서 · 바탕화면 등)에 풉니다. Program Files 처럼 권한이 막힌 곳은 피하세요.
  2. run.bat 을 더블클릭합니다. 검은 명령창이 뜨고 잠시 뒤 웹브라우저가 자동으로 열립니다.
  3. 안 열리면 브라우저 주소창에 직접 입력: http://localhost:8501
  4. 왼쪽 사이드바에서 원하는 화면을 고릅니다.
［ 스크린샷 자리 — 첫 화면(사이드바 메뉴) 캡처를 여기 넣으세요 ］
종료 — 검은 명령창을 닫거나 창에서 Ctrl+C. 파이썬 설치가 따로 필요 없습니다(폴더 안 python\ 사용). 처음 실행 시 방화벽이 “localhost 접근 허용?” 을 물으면 허용하세요.

2설정 DB LLM

무엇을 — LLM · Oracle 접속정보를 이 PC 에 저장합니다(.env). 스키마 추출·코멘트 증강 등 DB/LLM 이 필요한 화면을 쓰기 전에 가장 먼저 채워야 합니다.

어떻게 — 그룹(Oracle 접속 / LLM / 임베딩 …)별로 값을 입력하고 저장. 비밀번호는 화면에서 가려집니다.

항목설명
ORACLE_USER / PASSWORD / DSNAS-IS Oracle 접속 계정·주소
ORACLE_INSTANT_CLIENT_DIRInstant Client 폴더 경로(스키마 추출에 필요할 수 있음)
LLM_API_BASE / KEY / MODEL사내 LLM 게이트웨이(코멘트 증강 등)
여기 저장한 값은 이 PC 안에만 저장되고 외부로 전송되지 않습니다.

3스키마 추출 DB

무엇을 — Oracle DB 에서 테이블 · 컬럼 · PK/FK · 인덱스를 읽어 스키마 문서(.md) 로 만듭니다. 이후 코멘트 증강 · ERD · 마이그레이션의 기초 입력이 됩니다.

어떻게 — 형식(markdown/txt)·owner·table 을 지정하고 실행. 결과 .md 는 output\schema\ 아래에 날짜별로 저장됩니다.

「설정」에 Oracle 접속정보가 없으면 실패합니다. 먼저 2번을 완료하세요.

4코멘트 증강 LLM

무엇을 — 스키마 문서에서 코멘트가 비어 있는 컬럼에 LLM 이 한글 설명을 채워 넣습니다.

어떻게 — 스키마 .md 경로를 지정(최근 생성분 자동 연결)하고 실행 → …_enriched.md 생성. 이후 용어사전 · ERD 에서 이 파일을 쓰면 설명이 풍부해집니다.

5ERD 추출 / 보기 오프라인

ERD 추출

스키마 .md (+ 선택: mapper 폴더의 JOIN 관계) 로 관계도 HTML 을 만듭니다. 종류를 골라 실행하면 output\erd\ 에 인터랙티브 HTML 이 떨어집니다.

ERD 보기

만든 ERD HTML 을 화면 안에서 바로 엽니다(최근 생성 / 경로 지정 / 업로드).

폐쇄망에서 그림이 안 그려지면 D3 라이브러리 로컬 반입이 필요합니다(관리자 문의).
［ 스크린샷 자리 — ERD 보기 화면 캡처 ］

6표준사전 적재 / 용어 검색 오프라인

표준사전 적재

단어 · 용어 · 도메인 Excel 을 읽어 내부 사전(SQLite)에 적재합니다. 적재는 1회면 되고, 다시 적재하면 기존 내용을 지우고 새로 넣습니다.

용어 검색

적재된 사전을 단어/용어/도메인별로 검색합니다(만료 항목 포함 토글).

7매핑 만들기 오프라인

무엇을 — AS-IS → TO-BE 컬럼 매핑을 만듭니다. 마이그레이션이 “옛 테이블/컬럼 → 새 이름” 을 아는 근거가 되는 파일(column_mapping.md · .yaml)입니다.

방법 ① 엑셀 템플릿 + 매크로 (권장)

  1. 화면에서 9컬럼 엑셀 템플릿과 매크로 파일(.bas) 을 내려받습니다.
  2. 엑셀에서 Alt+F11 → 파일 가져오기로 .bas 추가, “매크로 사용 통합문서(.xlsm)” 로 저장.
  3. 9개 열을 채우고 ExportMappingMd 매크로 실행 → 같은 폴더에 column_mapping.md 생성(UTF-8, 한글 OK).

방법 ② 매크로 없이 — 엑셀 업로드 → MD·YAML 바로 변환

9컬럼을 채운 엑셀 파일을 화면에 업로드하면 MD 와 매핑 YAML 을 즉시 만들어 줍니다.

방법 ③ 기존 MD → 매핑 YAML

이미 만든 .md(예: 매크로 산출물)를 붙여 넣어 매핑 .yaml 로 변환합니다.

매핑이 수만 건이면 미리보기는 앞/뒤 몇 줄만 보여줍니다(브라우저 멈춤 방지). 전체 결과는 저장 파일에서 확인하세요.

8SQL 마이그레이션 오프라인

무엇을 — MyBatis/iBatis mapper XML 을 매핑에 따라 TO-BE 로 변환하고, 변환 XML 과 리포트를 만듭니다.

모드입력출력
파일 업로드XML 파일 몇 개 업로드변환 결과를 zip 으로 다운로드
폴더 지정프로젝트 폴더 경로지정한 출력 폴더에 입력 폴더 구조 그대로 XML 생성
  1. 모드(파일/폴더)를 고르고 입력을 지정합니다.
  2. 매핑(7번에서 만든 .yaml/.md)을 연결합니다.
  3. 옵션(한글 주석 삽입, 검증 skip, LLM 사용, 스키마 지정/파생)을 선택하고 실행.
폴더 지정 모드는 진짜 MyBatis/iBatis mapper XML 만 골라 변환합니다 (pom.xml·web.xml·빌드 산출물 등은 자동 제외).
［ 스크린샷 자리 — 마이그레이션 실행 결과(리포트) 캡처 ］

  3. 표준사전 적재 — 단어/용어/도메인 Excel 적재 (한 번).
  4. 매핑 만들기 — AS-IS→TO-BE 컬럼 매핑 작성.
  5. SQL 마이그레이션 — mapper XML 변환.

10자주 묻는 질문

브라우저가 안 열려요

주소창에 http://localhost:8501 을 직접 입력하세요. 검은 명령창은 켜 둔 채로 두어야 합니다.

“cp949 / 인코딩” 오류가 나요

최신 버전에서 해결되었습니다. 관리자에게 최신 배포판을 받으세요.

매핑 변환이 0건으로 나와요

엑셀 매크로로 만든 MD 는 최신 버전에서 정상 인식됩니다(BOM 문제 해결). 최신 배포판인지 확인하세요.

인터넷에 뭔가 전송되나요?

아니요. 이 도구는 localhost 에서만 동작하며 외부로 아무것도 보내지 않습니다. Oracle/LLM 접속은 사내망 안에서만 이뤄집니다.

결과 파일은 어디에 있나요?

output\<영역>\<날짜>\ 폴더(스키마/erd/migration …). 마이그레이션 폴더 모드는 지정한 출력 폴더에 생성됩니다.
